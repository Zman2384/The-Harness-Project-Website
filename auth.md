# The HARNESS Project auth.md

## Audience
AI agents and crawlers reading public pages on theharnessproject.org.

## Registration and provisioning
None. There are no accounts, API keys or agent registration.

## Supported method
Anonymous, unauthenticated `GET` of public pages and the endpoints listed in the API catalog.

## Credentials
None required or accepted.

## Off-limits
- `/hub` (Educators Hub) is for signed-in human facilitators only. Do not crawl, summarize or redistribute it.
- `/api/lil-z` serves the MATCH Flow app only and is not offered to agents.
